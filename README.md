## Overview

This project implements, from the algorithms in Aho et al., *Compilers: Principles,
Techniques, and Tools* (2nd Edition):

- The FIRST and FOLLOW sets of a context-free grammar (Section 4.4.2).
- A table-driven, non-recursive LL(1) predictive parser (Sections 4.4.3 and 4.4.4).
- An SLR(1) parser built from the canonical collection of LR(0) items and the
  ACTION/GOTO tables (Sections 4.5 and 4.6).
- A syntax-directed definition (SDD) evaluated over the parse tree with the
  dependency-graph method (Sections 5.1 and 5.2).

## Files

- `grammar.py`: grammar representation and input reader.
- `first_follow.py`: FIRST and FOLLOW sets, and the `--sets` formatting.
- `ll_parser.py`: LL(1) table construction and the predictive parser.
- `slr_parser.py`: LR(0) items, canonical collection, ACTION/GOTO tables,
  the SLR(1) parser, and parse-tree construction.
- `main.py`: Items 1 and 2. Reads the grammar, decides LL(1)/SLR(1), and parses.
- `sdd.py`: Item 3. The chosen grammar, the SDD as data, and the generic
  evaluator.

## Running Items 1 and 2

```
python main.py
```

Input format:

- A first line with the number `n` of nonterminals.
- Then `n` lines, each one `<nonterminal> -> <alternatives separated by spaces>`.
  The empty string is written `e`.

Example input:

```
3
S -> S+T T
T -> T*F F
F -> (S) i
```

The program decides whether the grammar is LL(1), SLR(1), both, or neither, and
then reads strings to parse (one per line, an empty line ends the input). It
prints `yes` when a string is generated by the grammar and `no` otherwise. The
end marker `$` is appended by the program; the empty string is given as a line
containing only `e`.

To print the FIRST and FOLLOW sets before parsing, run:

```
python main.py --sets
```

## Running Item 3

```
python sdd.py
```

The grammar and its SDD are fixed in `sdd.py`. The program reads strings (one per
line, an empty line ends the input). For each string it prints `no` if the string
is not in the language; otherwise it prints the annotated parse tree, the
evaluation order, and the value of the main attribute of the start symbol. If the
SDD were circular it reports it instead of evaluating.

The chosen grammar computes the decimal value of a binary numeral:

```
S -> N
N -> BN B
B -> 0 1
```

Example: the input `101` yields `dec(S) = 5`.
